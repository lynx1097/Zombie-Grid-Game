# Assets

## Character Sprites (`src/main/resources/icons/Characters/`)

All character sprites (Marcus Rowe, Victor Cole, Sara Chen, Iris Wade, Lena Park,
Rex Holt, Nadia Cross, Owen Blake, Zombie) are **generated programmatically** using
Java2D (`javax.imageio`, `java.awt.Graphics2D`). They are original work — colored
circle icons with character initials, role-coded by color (red = Fighter,
green = Medic, blue = Explorer, dark grey = Zombie).

No third-party character art is used.

## Music

No music assets are included in this repository. The sound system is currently
stubbed out. Royalty-free tracks can be added from sources such as
[Freesound.org](https://freesound.org) (CC0 / CC-BY) or
[Pixabay](https://pixabay.com/music/) (Pixabay license) — add them to
`src/main/resources/Sounds/` and update this file with proper attribution.
